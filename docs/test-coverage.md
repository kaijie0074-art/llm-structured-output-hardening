# 覆盖场景说明（test-coverage.md）

33 个测试用例的覆盖矩阵。原则：每个故障层至少 1 个语料场景 + 1 个单元级用例双向覆盖。

## L1-L2 词法语法层

| 场景 | 用例 | 断言 |
|---|---|---|
| ```json 围栏 + 前后缀寒暄（语料 01/05） | 语料场景终态 01/05 | 终态 OK |
| 围栏剥离单元 | fenceStripper剥离围栏与前后缀 | 剥出 {..} 跨度 |
| 中文引号定界值（语料 02） | 语料场景终态 02 + lenientRepair修复中文引号值 | 修复后 parse OK |
| 单引号键值 + 尾逗号（语料 03/04） | lenientRepair修复单引号与尾逗号 | 输出严格相等 |
| **值内部中文引号不误伤**（评审#2） | lenientRepair不误伤字符串内容里的中文引号 | "参与" 原样保留 |
| 截断识别 | 截断JSON被识别且不硬补 | 逗号/冒号结尾 true；完整 false |

## L3 结构层

| 场景 | 用例 | 断言 |
|---|---|---|
| 必填缺失/分数越界 | schema拦截缺必填字段与越界分数 | schema 违规非空 |
| path 索引越界（语料 06） | 语料场景终态 06（重试后 OK）+ field越界被识别为结构违规 | FIELD_TARGET_INVALID |
| 字段改名（语料 07） | 语料场景终态 07 | schema 拒→重试→OK |
| 截断可恢复/不可恢复（语料 14/15） | 语料场景终态 14/15 | OK（重试）/ FAILED |

## 重试纪律

| 场景 | 用例 | 断言 |
|---|---|---|
| 上限 | 重试硬上限恰好1次 | attempts==2 封顶 |
| 分流 | 捏造违规不触发重试 | attempts==1、无 RETRIED |
| 零浪费 | 干净输出不重试 | attempts==1 |
